# TravelNote — «Дневник путешествий»

Учебное приложение для кейс-задачи №5 производственной практики.

## Возможности
- регистрация и вход пользователя;
- создание записи о путешествии;
- просмотр путешествий других пользователей;
- редактирование и удаление собственных записей;
- геопозиция: координаты можно ввести вручную или получить через браузер;
- ссылка на точку в OpenStreetMap без платного API;
- изображение места с локальной загрузкой;
- стоимость путешествия.

## Запуск
Требуется Python 3.10+; сторонние библиотеки не нужны.

```bash
python app.py
```

Открыть: http://127.0.0.1:8003

Демо: `traveler` / `travel123`.

База `travel.db` создаётся автоматически при первом запуске.
